# Observability Baseline

## Logs
- Structured logs for key flows.
- Correlation/request identifiers when applicable.
- Avoid sensitive data leakage.

## Metrics
- Latency, error rate, throughput minimum.
- Resource usage metrics for runtime health.

## Alerts
- Alerts for sustained failures and availability drops.
- Alert noise controlled with clear thresholds.

## Verification
- Confirm signals exist before and after deploy.
