# Delivery Pipeline Checklist

## Build And Test
- Reproducible build commands.
- Mandatory tests and checks are explicit.
- Failing checks block deploy.

## Release Flow
- Environments and promotion path are clear.
- Release artifact/versioning is explicit.
- Rollback path exists for medium/high-risk changes.

## Operational Readiness
- Health checks are defined.
- Required runtime configs are documented.
- Post-deploy verification steps exist.
