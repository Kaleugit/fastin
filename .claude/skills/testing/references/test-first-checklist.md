# Test-First Checklist

Before implementation:
- [ ] Requirements are clear.
- [ ] Acceptance criteria are explicit and measurable.
- [ ] Test levels selected by risk.
- [ ] Requirement-to-test mapping exists.
- [ ] Open testing questions are resolved with human (if any).

Before completion:
- [ ] Planned tests executed.
- [ ] Critical paths covered.
- [ ] Acceptance criteria marked `PASS`/`FAIL` with evidence.
- [ ] No test was weakened to force pass.
- [ ] New/changed application source files are under `src/` (or `*/src/` in monorepo).
